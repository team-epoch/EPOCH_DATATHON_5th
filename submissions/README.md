# 제출 규칙

## 자기 팀 폴더에만 넣습니다

```
submissions/team03/
├── README.md        ← 팀 정보를 채워주세요 (필수)
├── code/            ← 최종 코드 .ipynb
├── slides/          ← 발표 자료 .pptx 또는 .pdf
└── submission/      ← 리더보드에 낸 최종 CSV (선택)
```

**다른 팀 폴더는 건드리지 마세요.** 충돌이 나면 양쪽 다 밀립니다.

---

## 파일 이름

**정해진 규칙은 없습니다.** 다만 아래를 지켜주시면 채점이 빨라집니다.

| | 권장 | 피해주세요 |
| --- | --- | --- |
| 코드 | `team03_final.ipynb` | `Untitled.ipynb` · `최종_진짜최종.ipynb` |
| 발표 | `team03_slides.pdf` | `발표.pptx` |

**한글 파일명도 됩니다.** 다만 맥·윈도우를 섞어 쓰면 깨질 수 있으니
**영문 + 숫자**를 권합니다.

---

## 여러 번 올려도 됩니다

마감 전까지 몇 번이든 덮어쓸 수 있습니다.
**마감 시각에 폴더에 있는 것**이 최종 제출물입니다.

---

## 새 팀이 생기면

`_template/` 을 복사해서 이름만 바꾸면 됩니다.

```bash
cp -r submissions/_template submissions/team07
```

---

## 체크리스트

제출을 끝내기 전에 한 번만 봐주세요.

- [ ] `README.md` 의 팀 정보를 채웠다
- [ ] `code/` 에 `.ipynb` 가 있다
- [ ] `slides/` 에 `.pptx` 또는 `.pdf` 가 있다
- [ ] 코드에 **절대 경로**(`C:\Users\...`)가 없다
- [ ] **랜덤 시드**를 고정했다
- [ ] 데이터 파일을 같이 올리지 않았다
- [ ] 다른 팀 폴더를 건드리지 않았다
